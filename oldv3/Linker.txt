EXTERNAL LINKS & ASSETS
EXTERNAL BINARY DEPENDENCIES
================================================================================

Assets/7zip/
└─ 7za.exe (Main compression engine used by DownloadZip and MadeChanges)
assets/7zip/7za.exe
└─ Used by: WDLauncher, RJLInstaller, MadeChanges
   (Requirement for .zip extraction of Minecraft assets and Launcher updates)

RJLData/LTheme/
├─ theme.json (Active theme selection)
├─ frcthe.json (Theme persistence/force flags)
└─ themes/<ThemeName>/
   ├─ theme<Name>.json (The Main Config described in newthemesystem.txt)
   ├─ theme<Name>.cfg (Metadata for Selector UI)
   └─ <Name>.banner (Custom text slide content)
WebView2Loader.dll (Windows Only)
└─ Used by: WDLauncher (Required for webview.h / Microsoft Login)

RJLData/userdata/
└─ [OFFLINE | MICROSOFT | ELYBY] (Account JSON profiles managed by sessionman.h)
